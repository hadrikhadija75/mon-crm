# Mon CRM

CRM très simple pour suivre mes prospects (vente de sites web aux entreprises).

## Fonctionnalités

- **Fiches prospects** : entreprise, contact, téléphone, email, site actuel, notes.
- **Pipeline de vente** en 4 colonnes : À contacter → En discussion → Gagné → Perdu.
  Glisser-déposer une carte pour changer d'étape.
- **Recherche** instantanée.
- **Exporter / Importer** : sauvegarde des données dans un fichier `.json`.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages
(Settings → Pages → Branch `main` / root) pour l'utiliser en ligne.

## Important : où sont mes données ?

Les données sont enregistrées **dans le navigateur** (localStorage), sur l'appareil utilisé.
Elles ne sont pas envoyées sur GitHub. Pensez à cliquer régulièrement sur **Exporter**
pour garder une sauvegarde, et utilisez **Importer** pour les retrouver sur un autre appareil.
